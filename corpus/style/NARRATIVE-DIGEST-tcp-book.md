# 样本二：TCP 小册的叙事手法拆解

> **样本**：《深入理解 TCP 协议：从原理到实战》，前 3 篇
> —— 开篇词 / TCP IP 历史与分层模型 / TCP 概述
> **性质**：`corpus/style/COURSE-STYLE.md` 管的是**句法**（字、词、标点、禁用句式）。
> 本文管**叙事与结构**：一节课怎么起手、怎么留住人、怎么收尾。
> **不冲突**：句法冲突一律以 COURSE-STYLE 为准。本文只补它没覆盖的那一层。

---

## 0. 一句话说清他强在哪

**他强在「让读者看见」，不在「把话说漂亮」：开头一句话把事说完，然后让你当场打开工具看一眼；中间插一段自己当年没弄懂的经历，把人拉到自己这边；最后留一道没答案的题。**

句法层面他其实不严格——分句长、句号少、有错字、有口号。**能学的全部在结构层，不能学的全部在句法层。**

---

## 1. 三篇的骨架长什么样

| 篇 | 起手 | 主体 | 收尾 |
|---|---|---|---|
| 开篇词 | 「这本小册是比较偏底层原理的」直接说门槛 | 六组小标题：基础 / 环境 / 内容 / 阅读顺序 / 答疑 / 参考书 | 俗语 + 一句启动语 |
| 历史与分层 | 先给 1969 → 1983 两个年份 | 抓包截图 → 四层逐个解释 → 「分层的好处」四条 | 一道习题，无答案 |
| TCP 概述 | **一句话定义** | `0x01`–`0x04`，每个特性一节 | `0x05` **原句复述** + 一道思考题 |

三篇的开头都是同一个路子：**第一段就把结论按在桌上**。没有背景铺陈，没有「本章将介绍」。

## 2. 九个手法

每条给原文证据、本项目对应位置、采不采纳。

### 手法一：开头一句话把全篇说完，结尾原样再说一遍

原文（TCP 概述，首段）：

> 如果要用一句话来描述 TCP 协议，我想应该是：TCP 是一个可靠的（reliable）、面向连接的（connection-oriented）、基于字节流（byte-stream）、全双工的（full-duplex）协议。

原文（同篇 `0x05`，第一句）：

> TCP 是一个可靠的（reliable）、面向连接的（connection-oriented）、基于字节流（byte-stream）、全双工（full-duplex）的协议。

中间隔了三千字，**一个字没改**。读者合上文章时，脑子里剩下的就是这一句。

**我们现在的写法**：`本课要点` 是 6 条 bullet，读完记住的是「六件差不多重要的事」，等于没重点。

**改法（规则 A）**：每课写一句总括句，≤ 30 字，句式 `X 就是 Y` 或 `X 用 Y 换 Z`。

- 位置一：`## 本节目标` 之前，作为开场第二段，加粗独立成行
- 位置二：`本课要点` 容器的**第一行**，原样重复
- 约束：两处必须是同一句，不得改写、不得缩写

已定的一句示范（RDMA 课）：**RDMA 用「砍掉中间层」换来微秒级稳定时延，代价是把丢包从常态变成事故。**

### 手法二：先给一条能跑的命令，让人看见东西，再讲原理

原文（分层篇）：解释「分层」之前，先给一个读者能照抄的三步。

> 打开 wireshark，在弹出的选项中，选中 en0 网卡，在过滤器中输入 `host www.baidu.com`，只抓取与百度服务器通信的数据包。
> 在命令行中用 curl 命令发起 http 请求：`curl http://www.baidu.com`

然后才列出 `Ethernet II → IPv4 → TCP → HTTP` 四行。**抽象概念在读者眼里有了形状，后面怎么讲都省力。**

**我们现在的写法**：机制课从表格开始（三笔代价 / 四差异 / 六计数器）。信息密度高，但读者前十秒没有「看见」任何东西。

**改法（规则 B）**：机制类课在 `## 机制拆解` 首个小节之前，放一条 **≤ 3 行**的观测命令。

- 命令 + 「你该看到什么」一句，不解释原理
- 零依赖优先：`ibv_devinfo`、`ethtool -S`、`ss -ti`、`nvidia-smi topo -m`
- 硬约束：**该命令必须在本课 lab 里能跑通**，否则删掉，不许写成「在某台机器上」

### 手法三：讲一次自己当年没弄懂的地方

原文（分层篇）：

> 记得在学习计算机网络课程的时候，一上来就开始讲分层模型了，当时死记硬背的各个层的名字很快就忘光了，不明白到底分层有什么用。

这句话干了三件事：承认读者现在的困境、把自己放到读者同一侧、给「为什么这一篇值得读」一个私人理由。

**我们现在的写法**：现有开头几乎全部是「上一课确立了结论：……」——正确、清晰、但冷。读者永远站在门外。

**改法（规则 C）**：讲一次自己当年没弄懂的地方，每课 ≤ 1 处，只允许放在 `::: info 经验映射` 容器里，句式定为：

> 我一开始以为 X。后来把 Y 拆开看，才知道 Z。

模板里刻意不用「直到……才」，它在 `COURSE-STYLE §9.1` 的禁用表里。

三条禁令：不卖惨、不自夸、不复述课程大纲。没有真实素材就**不写**，不许编。

### 手法四：用生活里的事打比方

原文（分层篇，讲端口号）：

> 假设你正在电脑上用微信跟女朋友聊天，用 QQ 跟技术大佬们讨论技术细节，当电脑收到一个数据包时，它怎么知道这是一条微信的聊天内容，还是一条 QQ 的消息呢？

「区分复用」这个抽象问题，一句生活场景就落地了。

**我们现在的写法**：`COURSE-STYLE §5` 的参照系清单只到技术层（Go / 消息队列 / TCP / 数据库 / 运维）。日常场景类比几乎为零。

**改法（规则 D）**：打比方多一档「生活场景」，每课 ≤ 1 处，只用来解释四类基础概念——**区分 / 排队 / 复用 / 反压**。不拿它当论据。

与现有禁令的关系：科幻、战争、体育比喻仍然禁用。日常场景必须来自运维以外的普通生活，且不得出现人名、品牌软广。

### 手法五：不确定的地方列出来，别装成定论

原文（字节流篇）：

> 情况 1：分为两条报文依次发出去 500 字节和 800 字节……情况 4：第一部分的 400 字节单独发送……情况 N：还有更多可能的拆分组合
> 上面出现的情况取决于诸多因素：路径最大传输单元 MTU、发送窗口大小、拥塞窗口大小等。

四行枚举 + 一句变量清单。读者得到的是「边界在哪」，而不是一个假的确定值。

**我们现在的写法**：语气偏「一句话定死」。遇到受环境影响的行为，容易写成断言，读者在自己的集群上一试不对，就失去信任。

**改法（规则 E）**：机制链存在环境依赖时，先给确定部分，再单起一段列变量：

> 确定的部分是：……。边界取决于三件事：X、Y、Z。

### 手法六：跳过的地方要说清楚什么时候回来

原文（TCP 概述）：

> 后面我们讲到超时重传模块的时候会详细介绍这部分内容。
> 这部分内容较复杂，后面有专门的文章进行讲解，这里先不展开。

**我们现在的写法**：大量超链接，但从不解释「为什么在这里停」。读者点走就散了。

**改法（规则 F）**：绕开一个机制时给两句——为什么现在不讲、什么时候必须回来。回来那处要给**文件链接 + 触发条件**：

> 这里先不展开，因为 ECN 标记率要配合队列水线才读得懂。等你做完 lab 07 再回来，那时你应该能回答这一课留下的问题。

### 手法七：每节末留一道没有答案的题

原文（分层篇结尾）只有一道 `## 习题`，答案是集中放在最后一篇《作业题和思考题解析》里。本节内**不给答案**。

**我们现在的写法**：四道题全带折叠答案。读者读答案比做题快，思考量归零。

**改法（规则 G）**：练习段末尾加一道 **开放题**，明说「本题不给参考答案」，条件指向 `labs/` 或读者自己的集群，答案要求是「贴一条证据」。

### 手法八：小节用 0x01 这类编号，方便回头引用

原文用 `0x01`–`0x05` 这种十六进制编号。便宜、好记、方便引用（「回到 0x03」比「回到第三个小节」利落）。

**判断：不采纳。** 本项目用 `## 本节目标 / 机制拆解 / 判读与实操` 六段结构，且 v1.0 已冻结（`docs/DECISIONS.md` D9）。编号与 VitePress 侧边栏重复，白加。

### 手法九：开头把门槛说清楚，反向筛人

原文（开篇词）：

> 这本书需要你了解基本的 linux 命令行操作，比如 ssh 登录服务器、vim、基本的文件命令等。

**我们已经有了**：`00-intro/01-lab-setup.md`。保持现状，但可以学他这么直白，不必要软化门槛。

## 3. 不该学的（抄了就是退步）

| 原文现象 | 原文例子 | 我们怎么处理 |
|---|---|---|
| 结尾口号与 emoji | 「让我们开启 TCP 协议的学习之旅吧。」/ 😁 | 禁。见 COURSE-STYLE §9 |
| 设问式小标题 | 「## 分层的好处是什么呢？」 | 禁。标题即判断，已清零 |
| 分句长、句号少 | 全篇密集逗号串，单段常 100 字以上 | 禁。COURSE-STYLE §4 规则一 |
| 第一人称高频 | 「我更偏好 iptables」「我想应该是」正文随处出现 | 限。`你 : 我 ≥ 3:1` 不动，仅规则 C 开一个口子 |
| 错字与格式失守 | 「不保证包是否会**达到**接收者」；CentOS 段用 `//` 当 shell 注释（语法非法） | 禁。命令块必须可直接执行 |
| 截图承载关键信息 | 全篇 20+ 张 jpeg，无替代文本 | 禁。改用「命令 + 预期输出」文本块，可 diff、可搜索 |
| 个人信息与书推广 | 微信号、公众号、付费小册宣传 | 禁。见 `docs/MIGRATION.md` 脱敏规则 |
| 答案延后到独立一篇 | 习题答案集中存放 | 不改。折叠答案保留，另加规则 G 的开放题 |

一句话收口：**他的叙事值得抄，他的排版不值得。**

## 4. 七条新规则（建议并入 COURSE-STYLE 作为 §14）

七条都能数出来。前六条进正文，第七条进脚本。

| 规则 | 内容 | 度量方式 | 每课配额 |
|---|---|---|---|
| **A** 开头结尾同一句 | `X 就是 Y`，≤ 30 字，开篇与要点卡首行**原样重复** | 人工核对两处字符串相等 | 1 句 |
| **B** 先跑命令再讲理 | `机制拆解` 前给 ≤ 3 行可执行命令，零依赖优先 | 本课 lab 能跑通 | 1 条 |
| **C** 讲一次自己没懂的地方 | `我一开始以为 X，直到看见 Y`，只在经验映射容器内 | grep「我一开始」 | ≤ 1 |
| **D** 日常场景 | 只解释区分 / 排队 / 复用 / 反压 | grep「假设你」 | ≤ 1 |
| **E** 说清楚依赖什么 | 先给确定部分，再写「边界取决于三件事：」 | 人工判别 | 有依赖处必写 |
| **F** 跳过要说清楚 | 为什么现在不讲 + 什么时候回来（含链接与触发条件） | 人工判别 | 每处跳过必写 |
| **G** 开放题 | 明确「本题不给参考答案」，答案要一条证据 | grep「不给参考答案」 | 1 道 |

脚本侧改动（`scripts/style-check.py`）：

- 新增计数 `anchor_sentence`：检测 `本课要点` 容器内是否存在与开场加粗行完全一致的句子，不一致时报警
- 新增计数 `i_story`：`我一开始|我曾以为` 命中次数，> 1 报错
- 新增计数 `daily_scene`：`假设你` 命中次数，> 1 报错
- 新增计数 `open_question`：`不给参考答案` 命中次数，0 时报警

**不要**把 A–G 加进硬指标报表的均值计算。它们是段落层面的东西，句长统计管不到，别混在一起算。

## 5. 示范改写：`site/docs/01-paradigm/03-rdma.md` 开场

改前（现状）：

> 上一课确立了结论：AI 训练网络要压丢包、压 MTTR。本课回答“为什么”的第一层：**为什么连 TCP 都不要了，非要绕过内核**？
>
> 理解了这一层的动机，后面的 PFC、ECN 你会自己推导出来，不需要背。

改后（规则 A + B）：

> 上一课定了结论：AI 训练网络要压丢包、压 MTTR。本课答第一层：**为什么连 TCP 都不要，非要绕过内核**。
>
> **一句话版：RDMA 用砍掉中间层换来微秒级稳定时延，代价是把丢包从常态变成事故。**
>
> 先量一个数字。同一对机器，两种路径：
>
> ```bash
> ib_write_lat -d mlx5_0 -s 64   # RDMA 小消息往返，典型 1–3 µs
> ping -c 5 <对端 IP>            # 内核路径往返，同机房通常几十 µs 量级
> ```
>
> 差一个量级。差的不是带宽，是**路径长度**。这一课讲的就是路径上被砍掉了什么，以及砍完要赔什么。

改动说明：

1. 保留原有判断句，不加背景、不设问
2. 插入那句总括句，加粗独立成段
3. 插入 `B` 观测动作（两行命令，都有 lab 支撑）
4. 结尾「砍完要赔什么」直接钩住本课的「代价」小节，替换掉原来「不需要背」这句宣言

## 6. 落地顺序建议

结构冻结（D9）之下，改动只走脚本与语句层，按投入产出排序：

| 序 | 动作 | 范围 | 成本 |
|---|---|---|---|
| 1 | 规则 A 开头结尾同一句 | 23 课 + 2 附录 | 每课加 2 行，判断难度中等 |
| 2 | 规则 G 开放题 | 23 课 | 每课加 1 题，可指向 `labs/` 对应实验 |
| 3 | 规则 B 先跑命令再讲理 | 14 篇机制课 | 需逐个确认 lab 可跑通 |
| 4 | 规则 C / D | 按素材有无，宁缺勿编 | 素材是最稀缺的 |
| 5 | 规则 E / F | 通读一遍，只在有依赖处补 | 低 |
| 6 | 脚本四条计数 | `scripts/style-check.py` | 1 小时 |

第 6 项先做，能让 1–4 项边改边验，避免又一次全站返工。

## 7. 一句话收尾

**学他开头一句话说到底、学他先让人动手看一眼、学他承认自己当年也不懂；别学他的句号和口号。**
