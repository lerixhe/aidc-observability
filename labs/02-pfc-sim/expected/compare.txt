== 02-pfc-sim · 场景对比 ==
拓扑 25 KB/μs × 4 上游 → 1 出端口 · ingress 缓冲 256 KB/口 · 出端口缓冲 192 KB · 时长 1000 μs

场景                                丢弃KB      ECN%   pause帧     覆盖率      利用率    F2达成率
----------------------------------------------------------------------------------------
idc 小流 · 无 PFC                       0      6.4%        0      0%      78%        -
incast · 无 PFC                    9170     97.1%        0      0%      43%        -
incast · PFC                         0     98.4%      360     53%      80%        -
incast · PFC + DCQCN                 0     31.8%       60      7%      80%        -
incast · PFC，pause 延迟 20μs        7170     95.0%      840     30%      51%        -
hol · PFC                            0    100.0%      700     89%      41%      10%

读法：
  1. idc 那行零触发零丢弃 —— 老面板搬到智算网络看到的就是这个
  2. incast 无 PFC 丢包、有 PFC 不丢但暂停成片 —— PFC 把丢包换成了堆积
  3. PFC + DCQCN 的 pause 帧数应显著下降 —— ECN 是主防线，PFC 是最后防线
  4. pause 延迟 20μs 那行开始丢包 —— pause 帧传播得越慢，缓冲越挡不住
  5. hol 行看 F2 达成率 —— 无辜流被同队列的慢流一起冻住
