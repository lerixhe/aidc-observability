## 这套材料讲什么

它只讲一件事：**AI 训练网络该看什么、为什么看、怎么看**。不是 RoCE / PFC 的协议综述，
而是「采集 → 指标 → 判读 → 定位」的完整链路，并且每个机制都配可复现的最小实验。

## 怎么用

- **顺序读**：M1 → M2 是机制地基，跳读会让后面的判读部分变成背书。
- **动手**：标注了 lab 的课程配可跑的实验（L1 层只需 Go / Python，无特权）。
- **自评**：每课练习先自己写，再展开参考答案对照评分维度。没有 AI 批改，也没有分数。
